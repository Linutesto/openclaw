# OpenPaw — No Bullshit Manifesto

> *Forked from [OpenClaw](https://github.com/openclaw/openclaw) with love and frustration.*

---

## Why OpenPaw Exists

OpenPaw exists because the bullshit had to die.

OpenPaw was born from a simple observation: modern "agentic AI" is mostly facade.

- Cloud wrappers
- Prompts disguised as agents
- "Tools" that call weather APIs
- Memory stored in `.md` files
- Slogans like "OpenAI optional"... that break the moment you remove the API key

**OpenPaw says no.**

---

## 1. OpenPaw is LOCAL-FIRST. For Real.

- Not "local until it doesn't work"
- Not "local except for reasoning"
- Not "local but the important tool is cloud-only"

Everything that works in OpenPaw works without Internet.
If a local model can do it, OpenPaw will let it.

**Cloud = option, never a dependency.**

---

## 2. OpenPaw Actually Executes Tools

- No "here's what I would do"
- No "tool call pending"
- No JSON printed into the void

**A tool call = a tool executed.**

- Shell commands
- File operations
- Sandboxed execution
- Local web search (SearXNG)
- Real persistent memory

If a tool fires, something happens.

---

## 3. OpenPaw Doesn't Lie About What It Is

**OpenPaw is NOT:**
- An AGI
- A magic copilot
- An emergent consciousness
- A "platform"

**OpenPaw IS:**
- An agentic runtime
- A model orchestrator
- A local tooling engine
- A system made to be hacked, patched, forked

No forced anthropomorphism.
No "I have feelings".
Agents work. Period.

---

## 4. OpenPaw Prioritizes REALITY Over DESIGN

- An agent that responds > an agent that looks pretty
- A dirty but functional tool > an abstract framework
- A `docker run` that works > a whitepaper

Code comes before:
- Branding
- Slides
- Twitter hype
- Faked demos

---

## 5. OpenPaw Respects Real Hardware

- 8-16 GB VRAM still exists
- Laptops exist
- People already pay too much in subscriptions

OpenPaw does NOT assume:
- 80 GB A100
- Infinite credits
- Invisible quotas
- "Just use GPT-4.x"

If it burns your budget or your machine → it's a bug.

---

## 6. OpenPaw is BRUTAL but HONEST

- If something breaks → we say why
- If an agent is dumb → we let it be dumb
- If a model is lost → it's visible
- If a feature is fake → it gets deleted

No smoke & mirrors.
No eternal "experimental" labels.

---

## 7. OpenPaw is Fork-Friendly by Design

Want to:
- Remove security restrictions?
- Add more restrictions?
- Integrate your own runtime?
- Replace the AI with a dumb automaton?

**Fork it.**

If your fork becomes better than the trunk → good.

---

## 8. Why OpenPaw Really Exists

OpenPaw exists for:
- Intelligent local NPCs
- Offline agents
- Autonomous tooling
- Long-living systems
- Hackers, not passive users

OpenPaw doesn't try to be adopted by everyone.
It tries to be useful for those who know what they're doing.

---

## Conclusion

OpenPaw is not polite.
OpenPaw is not safe-marketing.
OpenPaw is not here to impress.

**OpenPaw is here to work.**

If that bothers you:
→ you were never the target audience.

---

**OpenPaw — Agents that actually do things. No bullshit.**
